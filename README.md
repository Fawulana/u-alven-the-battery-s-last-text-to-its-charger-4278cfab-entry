The phone battery's last text to its charger: at 1%, after powering everyone who picked it up all day, it saved its last bar for the one who fills it — plug me in before I go dark. A deterministic, offline, stdlib-only Python program that writes that single line (176 characters) to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
